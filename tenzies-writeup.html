Game Overview

Tenzies is a modern implementation of the classic dice game built with React. The objective is simple yet engaging: roll until all 10 dice show the same number. Players can hold dice between rolls to strategically achieve the winning condition.

Game Interface

Roll until all dice are the same. Click each die to freeze it at its current value between rolls.

Core Game Logic

State Management

// Main game state with dice array
const [dice, setDice] = useState(() => generateAllNewDice())

// Game win condition logic
const gameWon = dice.every(die => die.isHeld) &&
    dice.every(die => die.value === dice[0].value)

// Dice object structure
function generateAllNewDice() {
    return new Array(10)
        .fill(0)
        .map(() => ({
            value: Math.ceil(Math.random() * 6),
            isHeld: false,
            id: nanoid()
        }))
}

Interactive Functions

// Dice rolling mechanism
function rollDice() {
    if (!gameWon) {
        setDice(oldDice => oldDice.map(die =>
            die.isHeld ?
                die :
                { ...die, value: Math.ceil(Math.random() * 6) }
        ))
    } else {
        // Reset game for new round
        setDice(generateAllNewDice())
    }
}

// Hold/unhold dice toggle
function hold(id) {
    setDice(oldDice => oldDice.map(die =>
        die.id === id ?
            { ...die, isHeld: !die.isHeld } :
            die
    ))
}

Component Architecture

Die Component

// Reusable Die component with accessibility
export default function Die(props) {
    const styles = {
        backgroundColor: props.isHeld ? "#59E391" : "white"
    }
    
    return (
        <button 
            style={styles}
            onClick={props.hold}
            aria-pressed={props.isHeld}
            aria-label={`Die with value ${props.value}, 
            ${props.isHeld ? "held" : "not held"}`}
        >{props.value}</button>
    )
}

Main App Component

// Dynamic dice rendering with React keys
const diceElements = dice.map(dieObj => (
    <Die
        key={dieObj.id}
        value={dieObj.value}
        isHeld={dieObj.isHeld}
        hold={() => hold(dieObj.id)}
    />
))

// Conditional rendering based on game state
return (
    <main>
        {gameWon && <Confetti />}
        <h1 className="title">Tenzies</h1>
        <p className="instructions">
            Roll until all dice are the same. 
            Click each die to freeze it at its current value between rolls.
        </p>
        <div className="dice-container">
            {diceElements}
        </div>
        <button ref={buttonRef} className="roll-dice" onClick={rollDice}>
            {gameWon ? "New Game" : "Roll"}
        </button>
    </main>
)

Game Mechanics

Rules Implementation

Game Flow:
  1. Start with 10 random dice showing values 1-6
  2. Click any die to "hold" it (turns green)
  3. Click "Roll" to reroll all unheld dice
  4. Continue holding dice and rolling until all 10 dice show the same number
  5. Win celebration triggers with confetti animation
  6. Click "New Game" to reset and play again

Win Condition Logic

// Two-part win condition check
const gameWon = dice.every(die => die.isHeld) &&
    dice.every(die => die.value === dice[0].value)

// Part 1: All dice must be held (player's intentional choice)
dice.every(die => die.isHeld)

// Part 2: All dice must show the same value
dice.every(die => die.value === dice[0].value)
