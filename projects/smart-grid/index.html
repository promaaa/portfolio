1. System Architecture

The system uses a two-stage measurement approach: current sensing via Hall effect (ACS712) and voltage sensing via transformer isolation (ZMPT101B). The ESP32 samples both at 2kHz, computes RMS values over each AC cycle, and streams JSON packets to connected clients.

Power Calculation

For AC circuits, real power accounts for phase shift between voltage and current:

Preal = Vrms × Irms × cos(φ)

Where cos(φ) is the power factor, computed from instantaneous V×I samples over one AC cycle.

Design Decisions

  • Hall-effect over shunt — Provides electrical isolation without circuit interruption
  • 2kHz sampling — Captures harmonics from switch-mode power supplies
  • USB power — Simplifies deployment, ~0.65W consumption

3. Calibration & Results

Calibration Methodology

Four-step process using a Fluke 115 as reference:

  1. Zero-point — Record quiescent voltage (2.5V typical)
  2. Multi-point — Test at 0%, 25%, 50%, 75%, 100% of range
  3. Linear regression — Calculate slope and offset corrections
  4. EEPROM storage — Save calibration constants

4. Firmware & API

Measurement Algorithm

// Sample over one AC cycle (20ms @ 50Hz)
void measurePower() {
  float sumV = 0, sumI = 0, sumP = 0;
  int samples = 0;
  
  unsigned long start = micros();
  while (micros() - start < SAMPLE_PERIOD) {
    float v = (readVoltage() - V_OFFSET) * V_SCALE;
    float i = (readCurrent() - I_OFFSET) * I_SCALE;
    
    sumV += v * v;
    sumI += i * i;
    sumP += v * i;
    samples++;
    delayMicroseconds(500);  // 2kHz
  }
  
  float Vrms = sqrt(sumV / samples);
  float Irms = sqrt(sumI / samples);
  float Preal = sumP / samples;
  float PF = Preal / (Vrms * Irms);
  
  sendToWebSocket(Vrms, Irms, Preal, PF);
}

7. Conclusions

This project demonstrates that accurate, real-time power monitoring is achievable for under $20 using commodity components. The ±1.34% accuracy exceeds design targets and approaches commercial meters at a fraction of the cost.

Limitations

  • Single-phase only (three-phase requires additional sensors)
  • 20A max current (ACS712-20A limit)
  • Power factor accuracy decreases with highly distorted waveforms
  • Not safety-certified for commercial deployment

Future Work

  • Machine learning — Appliance disaggregation via current signatures
  • MQTT integration — Home Assistant / OpenHAB compatibility
  • Multi-channel — Monitor multiple circuits simultaneously
  • Edge analytics — On-device anomaly detection
