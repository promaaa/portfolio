Smart Grid — Real-Time Data Ingestion & APIs

Overview

A comprehensive smart grid management system that handles real-time data ingestion from renewable energy sensors and provides enterprise-grade APIs for grid monitoring and control. Built with Java, Vert.x, and PostgreSQL, this system demonstrates scalable IoT architecture patterns.

Project Focus: Real-time sensor data processing, RESTful API design, and database modeling for energy grid management.

Architecture Overview

System Components

Sensors → UDP/HTTP Ingress → Vert.x Server → PostgreSQL Database → REST APIs

Key Features

🌍 Multi-Protocol Data Ingestion

  • UDP Server (Port 12345): High-frequency solar panel data streams
  • HTTP REST Endpoints: Wind turbine data ingestion
  • Real-time Processing: Automatic energy calculations and aggregation
  • Data Persistence: JPA-managed entity relationships

📊 Smart Grid Entity Model

  • Grid Management: Multiple grid support with user associations
  • Sensor Hierarchy: Producers (Solar Panels, Wind Turbines) and Consumers (EV Chargers)
  • Measurement Tracking: Temperature, power, energy consumption/production
  • User Management: Grid ownership and sensor access control

🔌 Comprehensive REST API

  • Grid Operations: Production/consumption monitoring
  • Sensor Management: CRUD operations for all sensor types
  • Data Retrieval: Historical measurements and real-time values
  • User Management: Person and ownership management

// Message format: id:temperature:power:timestamp
// Example: "2:25.4:523.6:1741334062"
private void processUDPMessage(String message) {
    String[] parts = message.split(":");
    int solarPanelId = Integer.parseInt(parts[0]);
    double temperature = Double.parseDouble(parts[1]);
    double power = Double.parseDouble(parts[2]);
    long timestamp = Long.parseLong(parts[3]);
    
    // Automatic energy calculation
    double newEnergy = prevEnergy + (power * (1.0 / 60.0));

    saveDataPoint(powerMeasurement, timestamp, power);

}

Real-Time Processing Features

Automatic Energy Calculations

The system automatically calculates cumulative energy production and consumption:

// Solar panel energy calculation (60-second intervals)
double newEnergy = prevEnergy + (power * (1.0 / 60.0));

// Wind turbine energy accumulation
double energyIncrement = power * timeDifferenceHours;
double newTotalEnergy = previousEnergy + energyIncrement;

Grid-Level Aggregation

Real-time grid production and consumption calculations using native SQL queries:

// Total grid production query
SELECT COALESCE(SUM(d.value), 0) 
FROM datapoint d 
JOIN measurement m ON d.measurement = m.id 
JOIN sensor s ON m.sensor = s.id 
JOIN producer p ON p.id = s.id 
WHERE s.grid = :gridId 
AND m.name = 'total_energy_produced' 
AND d.timestamp = (
    SELECT MAX(d2.timestamp) 
    FROM datapoint d2 
    WHERE d2.measurement = d.measurement
)
