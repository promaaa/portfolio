Project Overview

An autonomous robotics system designed to collect and sort colored balls in a competitive field environment. This project demonstrates the integration of mechanical design, embedded programming, and real-time control systems.

Core Challenge: Design and build autonomous robots capable of efficiently collecting colored balls while navigating obstacles and competing against other robots in real-time.

System Architecture

🤖 Mechanical Design

  • Chassis: Lightweight aluminum frame optimized for speed and maneuverability
  • Drive System: Differential drive with high-torque DC motors
  • Collection Mechanism: Custom-designed ball intake with rotating brushes
  • Sorting System: Color-based sorting mechanism with dedicated storage compartments
  • Sensors Integration: Ultrasonic sensors for navigation, color sensors for ball detection

🧠 Control Systems

  • Microcontroller: Arduino-based control system with real-time processing
  • PID Controllers: Multiple PID loops for motor control and trajectory following
  • State Machine: Robust state management for different operational modes
  • Sensor Fusion: Integration of multiple sensor inputs for decision making

PID Control Implementation

class PIDController {
private:
    double kp, ki, kd;
    double integral, previousError;
    unsigned long lastTime;
    
public:
    double compute(double setpoint, double input) {
        unsigned long now = millis();
        double timeChange = (now - lastTime) / 1000.0;
        
        double error = setpoint - input;
        integral += error * timeChange;
        double derivative = (error - previousError) / timeChange;
        
        double output = kp * error + ki * integral + kd * derivative;
        
        previousError = error;
        lastTime = now;
        
        return output;
    }
};

Color Detection System

typedef struct {
    int red, green, blue;
    String colorName;
} ColorProfile;

ColorProfile ballColors[] = {
    {255, 0, 0, "RED"},
    {0, 255, 0, "GREEN"},
    {0, 0, 255, "BLUE"},
    {255, 255, 0, "YELLOW"}
};

String detectBallColor() {
    // Read RGB values from color sensor
    int r = readRed();
    int g = readGreen();
    int b = readBlue();
    
    // Find closest color match
    int minDistance = INT_MAX;
    String detectedColor = "UNKNOWN";
    
    for (int i = 0; i < 4; i++) {
        int distance = sqrt(pow(r - ballColors[i].red, 2) + 
                          pow(g - ballColors[i].green, 2) + 
                          pow(b - ballColors[i].blue, 2));
        
        if (distance < minDistance) {
            minDistance = distance;
            detectedColor = ballColors[i].colorName;
        }
    }
    
    return detectedColor;
}
